Welcome to PuTTY-TDE Setup

PuTTY-TDE is a lightweight, native terminal emulator and SSH client designed specifically for Q4OS / Trinity Desktop Environment (TDE).

Key Features:

  • Pure TQt3: Native TDE interface without any GNOME or GTK dependencies.
  • Complete Protocol Support: SSH-1, SSH-2, Telnet, Serial (RS-232 / USB-TTY), Rlogin, and Raw connections.
  • Enhanced Usability: Persistent configuration window, unified username/password login, and dynamic status bar.
  • Unix Ergonomics: True X11 clipboard & PRIMARY selection, word/line selection, middle-click paste, and file drag-and-drop.
  • Ultra-Lightweight: Fast startup with minimal system resource consumption.
